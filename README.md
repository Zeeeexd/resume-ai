# resume-ai
ResumeAI – AI Resume Analyzer &amp; Career Assistant is a full-stack AI-powered web application designed to help job seekers improve their resumes and increase their compatibility with specific job roles. Users can upload their resume in PDF or DOCX format, select a target role, and optionally provide a job description.
